#  DSA Handbook


A personalized Data Structures and Algorithms handbook designed for developers to store, review, and master problem-solving. It features an interactive practice arena, machine learning-driven performance estimation, and automated AI code explanations.

👉 **Application Link:** [https://dsa-handbook.streamlit.app/](https://dsa-handbook.streamlit.app/)

---

## 🚀 Key Features

- 📖 **Structured Topic Breakdown:** Detailed categorization of core DSA concepts—from Arrays, Linked Lists, and Trees to Dynamic Programming and Graphs.
- 🏋️ **Gymkhana Practice Arena:** Targeted problem-solving mode equipped with custom ML models that predict the estimated time you will need to solve a specific problem based on your historical performance and problem difficulty.
- 🤖 **Automated AI Code Explanations:** Saves user solutions alongside generated explanations detailing time/space complexity, core logic, and edge cases.
- 📊 **Personalized Progress & Analytics:** Track solved problems, execution accuracy, and identify weak topics over time.
- 💡 **Interactive Visualizations:** Live, step-by-step visual representations of algorithm states and data structures.

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit, HTML5, CSS3, JavaScript
- **Backend:** Python (Streamlit framework & ML runtime)
- **Database:** MongoDB
- **Machine Learning & AI:** Scikit-Learn / ML pipelines (Time Prediction Model), LLM APIs (Automated Code Explanations)
